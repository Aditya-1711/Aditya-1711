### TriSAR – Task Coordination and Collision Avoidance for Aerial Robot Teams in Disaster Response

**Accepted at TAROS 2026 · arXiv:2609.01731**

Five-UAV coordination framework combining task allocation with reactive collision avoidance for disaster-response scenarios. Evaluated Genetic Algorithm and greedy allocation strategies across 120 stochastic Gazebo simulation episodes.
